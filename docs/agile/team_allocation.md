# Team Allocation & Roster

**Project:** FreshCart — Online Grocery Application  
**Team Size:** 5 Members  
**Agile Framework:** Scrum (adapted for academic jury delivery)

---

## Team Roles & Allocation

| Member | Primary Role | Secondary Responsibilities | Key Ownership Areas |
| :--- | :--- | :--- | :--- |
| **Member 1** | **Scrum Master & Product Owner** | Agile Documentation & Coordination | Product backlog prioritization, sprint ceremonies, Trello board tracking, Defect & Risk registers. |
| **Member 2** | **Frontend Lead** | UI/UX & Interaction Design | Next.js App Router setup, Tailwind CSS styling, responsive layout, homepage orbit carousel integration. |
| **Member 3** | **Backend Lead** | API Design & Database Architecture | FastAPI application structure, SQLAlchemy models, SQLite persistence, business logic, endpoints. |
| **Member 4** | **Full-Stack & Integration Engineer** | API Integration & State Management | Frontend-to-backend API wiring, Cart state management, Checkout flow, simulated payment handling. |
| **Member 5** | **QA & Test Engineer** | Verification & Test Documentation | Test case register, automated endpoint verification, validation testing, edge-case analysis. |

---

## Working Agreements
1. **Branching Strategy:** Feature branches branched off `main` (`feature/<feature-name>`); no direct pushes to `main`.
2. **Review Process:** Every pull request requires review against the Definition of Done before merging.
3. **Evidence Integrity:** No fabricated test results, metrics, or completion claims.
